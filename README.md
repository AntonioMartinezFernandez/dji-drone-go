# DJI drone Go

Experimental Go applications to control DJI drones.

## Naive

Take off, flip, and land.

```bash
make naive
```

## Keyboard Controller

Control the drone with the keyboard.

```bash
make keyboard
```

Use the following keys to control the drone:

```
------------------------------
           CONTROLS
------------------------------
 T - Take off
 L - Land
------------------------------
 P - Flip right
 O - Flip left
------------------------------
 W - Move forward
 S - Move backward
 A - Move left
 D - Move right
------------------------------
 U - Move up
 J - Move down
------------------------------
 ESC - Exit
------------------------------
```
